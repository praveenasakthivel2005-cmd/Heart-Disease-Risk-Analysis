# Heart Disease Risk Analysis

## Project Overview:

This project analyzes heart disease risk factors using Microsoft Power BI.

The dashboard helps understand patient data based on:
- Age
- Gender
- Cholesterol
- Blood Pressure
- Chest Pain Type
- Exercise Angina
- Resting ECG
- Maximum Heart Rate
- ST Slope

## Dashboard Pages

1. Overview
2. Risk Factors
3. Patient Insights

## Tools Used

- Microsoft Power BI
- DAX
- CSV Dataset

## Key Features

- Interactive dashboard
- KPI cards
- Charts and graphs
- Slicers and filters
- Patient risk analysis
